# PDF 교재 페이지 (벡터 배경 필기) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 교사가 챕터·과제에 PDF 파일을 등록하면 쪽마다 페이지가 생기고, 5개 필기 뷰어에서 어느 배율로 확대해도 선명한 벡터 배경 위에 필기할 수 있다.

**Architecture:** `pages`/`assignment_pages`에 `pdf_url`·`pdf_page`를 추가하고 원본 PDF를 `chapter-pdfs` 버킷에 한 번만 저장한다. 뷰어는 Excalidraw 아래에 `pointer-events: none` 캔버스(`PdfPageLayer`)를 깔고, Excalidraw `onChange`의 `scrollX/scrollY/zoom`을 받아 즉시 CSS transform으로 따라간 뒤 120ms 멈추면 pdf.js로 "종이 중 화면에 보이는 부분만" 현재 배율×DPR로 다시 그린다. 종이 사각형은 기존 `bgPosition` 계약 그대로이고 배경 image element는 만들지 않는다. 썸네일과 PDF 내보내기도 pdf.js 래스터로 처리한다(래스터 보관 없음).

**Tech Stack:** React 19 + Vite 7 + Excalidraw 0.18 + `pdfjs-dist` 6.4.299 (클라이언트), Fastify 5 + Drizzle 0.45 + PostgreSQL (서버), Vitest (클라이언트·서버 단위), Playwright (E2E 스모크).

**Spec:** `docs/superpowers/specs/2026-10-30-pdf-pages-design.md`

## Global Constraints

- 새 버킷 이름 `chapter-pdfs`, 허용 MIME `application/pdf`만, 상한 `100MB` (400 / 413).
- 등록 상한 `500쪽`, `100MB`. 메시지(정확히): "암호가 걸린 PDF는 등록할 수 없습니다." / "PDF를 읽을 수 없습니다." / "PDF는 500쪽 이하만 등록할 수 있습니다." / "PDF는 100MB 이하만 등록할 수 있습니다."
- 열람 메시지: "PDF를 불러오지 못했습니다" (+ 다시 시도), "쪽을 불러오지 못했습니다".
- 뷰포트 정지 판정 `120ms`, DPR 상한 `3`, 문서 LRU 캐시 `2`, 썸네일 너비 `240px`·캐시 `200`, 내보내기 긴 변 `1754px`(기존 `PDF_MAX_DIMENSION`).
- `pdfUrl`은 `/api/files/chapter-pdfs/`로 시작해야 하고 `pdfPage`는 1 이상 정수. 둘은 함께 있거나 함께 없다.
- 서버는 PDF를 파싱하지 않는다. 배경 image element(`__bg_image__`)는 PDF 페이지에 만들지 않는다.
- `pdfjs-dist` 6.4.299 고정. 설치 전 `supermatt:dependency-vetting`. pdf.js 접근은 `lib/pdfjs.js`를 통해서만.
- 커밋 메시지는 기존 관례(한국어 `feat(...)`/`fix(...)`/`docs:`) + 세션 attribution 꼬리.
- 각 Task 끝에 `npm run lint` (클라이언트 변경 시)와 해당 패키지 `npm test`가 통과해야 한다.

## Review Focus

1. **회전된 쪽(`/Rotate 90`)·쪽마다 크기가 다른 PDF** — 종이 비율은 MediaBox가 아니라 회전이 적용된 `getViewport({scale:1})` 크기를 써야 한다. → Task 5 `paperRectForPage` 테스트.
2. **극단 배율·화면 밖 종이** — zoom 0.05 또는 30에서도 캔버스가 픽셀 예산을 넘지 않고, 종이가 화면 밖이면 렌더를 건너뛰어야 한다(0×0 캔버스 금지). → Task 5 `renderPlan` 테스트.
3. **소수 DPR(1.25, 2.625)** — 캔버스 크기는 정수여야 하고 `MAX_DPR`로 잘려야 한다. → Task 5 `renderPlan` 테스트.
4. **이미지와 PDF를 섞어 고른 업로드** — 파일명 순서를 지키면서 PDF 한 파일이 쪽수만큼 연속 `position`을 차지해야 한다. → Task 9 `planPagePositions` 테스트.
5. **한글·공백 파일명 PDF** — 저장 URL에 한글이 그대로 들어가므로 pdf.js `getDocument({url})`가 그 URL로 열려야 한다. → Task 13 E2E 픽스처 이름 `교재 테스트.pdf`.

### Task 5: 레이어 수학 (`lib/pdfLayerMath.js`)

**Files:**
- Create: `packages/client/src/lib/pdfLayerMath.js`, `packages/client/src/lib/pdfLayerMath.test.js`

**Interfaces:**
- Produces (모두 순수 함수, 좌표는 Excalidraw 규칙 `screen = (scene + scroll) * zoom`):
  - `VIEWPORT_SETTLE_MS = 120`, `MAX_DPR = 3`
  - `type View = { scrollX, scrollY, zoom }`, `type Rect = { x, y, width, height }`(scene), `type Box = { left, top, width, height }`(CSS px)
  - `viewFromAppState(appState): View` — `{ scrollX, scrollY, zoom: appState.zoom.value }`
  - `sameView(a: View | null, b: View): boolean` — 세 값이 1e-6 이내면 같음
  - `sceneToScreen(rect: Rect, view: View): Box`
  - `visibleClip(paper: Box, container: { width, height }): Box | null` — 교집합, 너비·높이가 1px 미만이면 null
  - `clampDpr(dpr: number): number` — `Math.min(dpr || 1, MAX_DPR)`
  - `renderPlan({ paper: Rect, view: View, container: { width, height }, pageSize: { width, height }, dpr }): Plan | null` — `Plan = { css: Box, canvasWidth, canvasHeight, scale, offsetX, offsetY }`. `css`는 clip, `canvasWidth = Math.round(css.width * d)`, `scale = view.zoom * (paper.width / pageSize.width) * d`, `offsetX = -(css.left - paperScreen.left) * d` (offsetY 동일), `d = clampDpr(dpr)`. clip이 null이면 null.
  - `placeBitmap(rendered: { css: Box, view: View }, current: View): { left, top, scale }` — 렌더 당시 clip의 scene 원점을 현재 view로 다시 투영: `scale = current.zoom / rendered.view.zoom`, `left = (rendered.css.left / rendered.view.zoom - rendered.view.scrollX + current.scrollX) * current.zoom`.
  - `paperRectForPage(pageSize: { width, height }, container: { width, height }, savedBg: Rect | null): Rect` — `savedBg`가 있고 `width > 10 && height > 10`면 그대로, 아니면 `calculateBgPosition(container.width, container.height, pageSize.width, pageSize.height)`.

- [ ] **Step 1: Write the failing tests**

describe('sceneToScreen', () => {
