# 영상 플레이어 터치 = 조작 창 열기/닫기 — 설계 (짧은 변경)

작성일: 2026-11-13
상태: 대화로 확정(두 번 터치 이동 유지 · 꾹 누르기 표시 위로)

## 의도

지금은 영상을 손가락으로 살짝 터치하면 바로 재생/일시정지가 바뀐다. 필기하거나 화면을 만지다가 의도치 않게
멈추는 일이 생긴다. 교사는 터치를 **조작 창을 여는 동작**으로 바꾸고, 멈추고 싶을 때만 일시정지 버튼을 직접
누르게 하고 싶다(유튜브 앱처럼).

## 목표

1. 터치(손가락·펜) 한 번: 조작 창이 닫혀 있으면 **바로** 연다, 열려 있으면 **바로** 닫는다. 재생 상태는 바꾸지 않는다.
2. 조작 창 = 가운데 큰 재생/일시정지 버튼 + 그 양옆 뒤로·앞으로(설정의 이동 시간, 기본 10초) 버튼 + 기존 아래 재생 바.
3. 마지막 조작 후 **3초** 지나면 조작 창이 사라진다 — 재생 중이든 정지 중이든. 창 안 버튼을 누르면 3초를 새로 센다.
4. 두 번 빠르게 터치(350ms 안) = 지금처럼 오른쪽 절반 앞으로 / 왼쪽 절반 뒤로 이동. 이동 뒤엔 조작 창이 보이고 3초 뒤 사라진다.
5. 꾹 누르기 표시: 아래 설명 줄(`누르고 있는 동안 2배속 …`)을 없애고, `⏩ 2배속` / `⏪ 되감기 · 0:42` 알약만 **화면 위쪽 가운데**에 둔다.

### 비목표

- PC 마우스 동작 변경. 클릭 = 즉시 재생/정지, 마우스를 올리면 재생 바 표시, 정지 중 재생 바 유지 — 그대로.
- 끌기(시간 이동·볼륨·밝기), 꾹 누르기(2배속·되감기) 동작 자체, 키보드 단축키, 설정 메뉴.
- 마우스로 보는 화면에 가운데 버튼 묶음 추가.

## 접근

`VideoPlayer.jsx` 안에서 바꾼다. 기존 `controlsVisible` 상태와 숨김 타이머(`revealControls`)를 그대로 쓰고,
"마지막 입력이 터치였는가"를 기억해 (a) 가운데 버튼 묶음을 보일지 (b) 정지 중에도 숨길지를 정한다.
다른 길(별도 오버레이 컴포넌트 + 자체 타이머)은 재생 바와 숨김 규칙이 둘로 갈라져 버린다.

- 탭 판단은 순수 함수로 뺀다(`lib/videoPlayer.js`): 첫 탭은 창 토글, 350ms 안 두 번째 탭은 첫 탭의 토글을 되돌리고 이동.
- 숨김 규칙: 터치 모드면 3초 뒤 항상 숨김, 마우스 모드면 지금처럼 재생 중일 때만 숨김(2.5초).
- 정지 이벤트(`onPause`)가 창을 계속 띄워 두지 않도록, 터치 모드에서는 타이머로 숨긴다.

## 검증

- Vitest: 탭 판단 함수, 숨김 판단 함수.
- 브라우저(Playwright, 터치 지원 문맥): 터치 → 창 뜨고 재생 상태 그대로 / 다시 터치 → 창 닫힘 / 3초 뒤 자동 숨김(정지 중 포함) /
  가운데 일시정지 버튼 → 정지 / 두 번 터치 → 이동 / 꾹 누르기 알약이 위쪽에 있고 설명 줄 없음.
